# Publishing

Applies to every file here and to anything made from them: pages, Discord
posts, embeds, slides.

- Name players by character name. Applications and applicants stay with the
  officers and out of this repo.
- Summarise what people said. Quote someone only with their OK.
- Report performance at group level. Individual numbers live on Warcraft Logs.
- Leave out IDs (Discord, OXM, Battle.net), tokens, cookies, file paths and
  local system details.
- What leadership discusses privately enters only as a decision or
  direction that an officer chose to record.
- `main` holds rule, direction, practice and open items. A proposal is a
  pull request until officers merge it.
- Tone: direct, a bit of banter, plain words, like the guild's own rules.
- Anything visual follows `brand/theme.md`.
- A published page (`pages/`) shows a technical detail only in a "Technical
  details" section at the bottom, and never the items above.
