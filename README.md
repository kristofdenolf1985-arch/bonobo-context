# Bonobo guild context

What the guild has agreed on and what's still open: who we are, the rules,
each decision with where it was made, and raid reports. People and AI
assistants both read it. Point your assistant (Claude, ChatGPT or another) at
`AGENTS.md` and it knows how to use the repo and how to propose a change.

## Reading it

Browse the files on GitHub like a wiki. Start with `guild.md` and
`expectations.md`. `decisions/` has one file per decision; a decision marked
`open` hasn't been taken yet.

## Proposing a change

Anyone with access can propose a change, and officers decide what goes in.

An AI assistant with access to the repo can do it for you: ask it to add the
decision, raid report or fix, and it opens a pull request. If your assistant
can't reach GitHub, paste `AGENTS.md` into the chat, let it write the file,
and add the file yourself in the browser.

In the browser, open a file, click the pencil icon, make the change and pick
"Create a new branch and start a pull request". For a new decision, copy
`templates/decision.md` into a new file in `decisions/`.

A check runs on every pull request and says which field or file name needs
fixing. An officer then reviews and merges it.

## Right now

The repo is private and a few people are trying out the process. If it
works, it opens up to the whole guild.
